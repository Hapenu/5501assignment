不是替你占卜，
而是陪你记住。

月相札记是一本会回应的塔罗牌记：布置、抽牌、解读，然后把其中一句，写成你自己的话。它也是一个课程演示站：支付、订单与社区内容均为模拟。

The Problem

市面上的塔罗产品，
大多在替你回答。

选牌阵、点开始、看结果、付费解锁更详细的解释。这套流程很高效，但也把塔罗变成了一次性消费。你真正想做的，是让人留下来——把每一次抽牌变成可以翻阅、可以修订、可以对照的私人记录。

月相是周期，也是回看的时间刻度；札记是私人的、不完整的、允许反复批注的记录；Codex 是手抄本，暗示它会被翻阅，而不是被消费。

For Three People

三个具体的人

不写“18–35 岁玄学爱好者”这种谁都覆盖、谁都不像的描述。

01 / 林

自学三个月

想建立自己的理解，但网上释义互相矛盾，记了就忘。她需要牌库、牌阵、可对比的注疏，以及连续的牌记。

02 / 苏

五年爱好者

只想安静记录、偶尔共修；厌倦商业平台把解牌变成流量。她需要快速记录、私密模式、匿名分享单条记录。

03 / 岚

旅行者

不带牌也想抽；没有实体牌，就很难进入状态。她需要可布置的圣所、线上抽牌、临时牌记。

Business Model

商业性，
不等于真收款。

课程要求网站具备商业性。这个作品用完整的交易流程来证明它：服务预约、实物下单、虚拟器物兑换、订单状态与评价。支付是演示的，但商业逻辑是完整的。

收入来源怎么收费本作怎么演示
解牌服务按套餐收费，平台抽成 15%预约 → 演示支付 → 订单 → 交付 → 评价
实物器物商品差价 + 运费详情 → 购物袋 → 地址 → 演示支付 → 物流
虚拟器物¥ 购买或月华兑换购买 → 我的器物 → 在圣所中使用
本作不接入真实支付。所有“支付”“发货”“接单”都是本地状态，不会产生真实资金流。
Rules & Boundaries

规则与边界

解牌师是社区用户，不是平台客服

每位解牌师有自己的风格、价格、档期与评价。平台收取 15% 服务费，用于支付通道、订单与争议处理。解牌师不提供医疗、法律或投资建议；遇到越界，可以在订单里申请退款。

隐私

牌记默认只存在这台设备。分享是单条、可撤回的选择；AI 只会收到问题、牌阵与牌面，不会收到你的私人笔记。导出的 JSON 不包含 API Key。

AI

AI 是可选能力，采用 BYOK：你自己提供 OpenAI 兼容接口的 Key。Key 默认只存在 sessionStorage；勾选“记住”才写入 localStorage。纯前端 Key 对任何能打开网页的人都可见，课程本机演示没问题；公网部署请加一层转发，并使用限额 Key。

内容与版权

78 张牌面采用 Pamela Colman Smith 于 1909 年绘制的 Rider-Waite-Smith 图像，在美国属公有领域；本作品将其压缩为本地 360px JPEG，来源 Wikimedia Commons 与 the-arcana 仓库。牌义参考韦特体系的公共领域意象，由本作品重写；不引用在版书籍原文。字体使用系统宋体与无衬线，不下载外部字体。

无障碍

支持键盘操作、焦点环、减少动效与 200% 缩放；正逆位不只靠颜色区分，图表有文字摘要。目标是对比度 ≥ 4.5:1，触控目标 ≥ 44px。

Technical Notes

22 个静态页面，
0 个自建后端。

网站由 22 个 HTML 页面、一套 CSS token 与原生 JavaScript 构成，构建脚本只负责注入共享页头页脚。没有 npm、没有 CDN、没有外部字体；双击 index.html 也能打开。

数据存在 localStorage 的单一 store 里，带版本号、导出/导入与重置。AI 采用 OpenAI 兼容的 /chat/completions，失败时自动回退到本地注疏。

这是一个课程作业，不是商业产品。它展示的是：如何在“没有后端”的约束下，把一条完整体验与一套商业模式讲清楚。
