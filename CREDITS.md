# Rider-Waite-Smith card faces

- **Deck**: Rider-Waite-Smith, first published 1909.
- **Artist**: Pamela Colman Smith (1878–1951).
- **Status**: Public domain in the United States. The 1909 artwork is reproduced by Wikimedia Commons and other public-domain archives.
- **Source used here**: Wikimedia Commons files in the `Rider-Waite tarot deck` collection, downloaded through the MIT-licensed [`OrionJDev/the-arcana`](https://github.com/OrionJDev/the-arcana) repository (`cards/`), which credits Wikimedia Commons.
- **Processing**: resized to max 360 × 620 px, converted to JPEG (quality 84), stored locally for offline course use. File names use this project's card IDs (`major-00.jpg`, `cups-01.jpg`, ...).
- **Not included**: card back, product mockups and master sigils — those are original to this project.

If this site is published outside the US, check the copyright term in your jurisdiction; the 1909 RWS deck is public domain in the US, but rules differ elsewhere.
